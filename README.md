# Lakshya Hindocha — Portfolio

Personal portfolio website: a static site built with HTML, CSS and vanilla JavaScript.

- Responsive from small phones to 4K displays
- Project cards open a details popup with a screenshot gallery
- Contact links open Gmail compose (the Gmail app on mobile)

## Run locally
Open `index.html` in a browser.

## Add project screenshots
Put images in `images/<project>/` and list them under `shots` for that project in `script.js`.
